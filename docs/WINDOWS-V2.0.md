# 言渡 Windows V2.0（2.0.0）

Windows 1.2.1 经用户试用后按 V2.0 定版，正式标签 v2.0.0。程序与安装器内部版本为 2.0.0，原生模块沿用已验证的 1.2.1 功能构建，以新的版本文件名部署；没有只给旧安装包改名。

本次发布仅提供 Windows x64 安装器及对应源码。Android 保留 v1.0.0 原发布，未把旧 APK 标成 V2.0。

## 核心内容

- 完整原文截取、句首补字和译文陈述语义修复，保留精确范围校验后替换及同位置撤回。
- 内置 CC-CEDICT：125,403 条原始词条快照，中英双向压缩索引约 4.1 MiB。完整词条本地优先，整句未命中时请求已配置的 API；阅读结果支持主动 AI 精译。
- 划词“译”按钮与 Ctrl＋Alt＋Z 截屏共用原位覆盖／对照界面，按主要语言自动中英互译，支持复制与滚动。
- 强制密码保护与典型敏感内容拦截，不上传个人词库或缓存，不收集输入资料用于改进或训练；OCR 内存管道不生成新图片／文字临时文件。
- 真实安装进度、首次自选目录、升级保留配置，以及固定 GitHub 更新源。

详见 README、[隐私说明](PRIVACY.md)、[原文修复与实际测试](WINDOWS-V1.2.1.md) 和 [词典说明](WINDOWS-V1.2.md)。词典不是离线整句模型，第三方 API 的留存规则不受本项目保证。

## 验证与安装

功能沿用此前通过的 32／64 位原生控件与隔离浏览器测试，以及完整句子真实 API 检查。V2.0 重新编译助手和安装器，检查内部版本、词典校验、内嵌包以及更新识别。此次没有再次执行系统覆盖安装，不承诺全部应用兼容。

运行 Yandu-Setup-x64.exe 覆盖升级，保留安装位置和个人配置。安装后重新打开已加载旧模块的浏览器、微信等应用；需要时注销再登录。安装和系统注册需要 Windows 管理员确认。
