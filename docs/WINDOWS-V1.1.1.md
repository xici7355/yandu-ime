# Windows V1.1.1：原位截图翻译与自动互译

## 本次调整

截图选区使用预先暗化的背景，拖动时按固定节奏更新局部区域。释放鼠标后固定选区，排队的鼠标移动不再改变结果；鼠标捕获异常中断时取消操作。Ctrl＋Alt＋Z、Esc 和右键取消保留。

截图结果留在当前截图上，不打开居中的双栏结果窗口。工具栏提供“对照”“复制译文”“复制原文”“重试”和“关闭”，不添加朗读。

- 关闭对照：译文直接覆盖选中的原图文字区域。
- 打开对照：原图保留，译文优先放在选区上方或下方的可用位置。
- 长段译文限制在屏幕内，可滚动查看和完整复制。极大选区没有足够外部空间时，译文卡片会使用屏幕内的位置。

对照偏好会在手动切换时保存。重新截图会关闭前一次结果，取消重新截图则恢复前一次结果。

## 自动语言方向

截图和划词根据原文主要语言自动选择：中文译为英文，英文译为简体中文。中英混合内容按主要文字判断，常见中文句中的 API 等技术词不会单独把方向切成英译中。界面显示当前方向，划词结果相应标注“中文译文”或“英文译文”。

普通输入过程仍按既有中译英流程工作。翻译缓存按目标语言区分，不会把同一原文的中英文译文混用。英译中结果的末尾标点会在本地转换为中文标点。

用户确认，先前的中译英接口本身正常；原文已为英文时输出英文并非接口故障。本次增加自动互译满足新的使用方式，不将此误记为已修复的接口问题。

## 识别与错误提示

本机 OCR 在默认布局识别为空时，会尝试稀疏文字或单行布局。识别中、翻译中、超时及接口配置问题均在截图附近显示；失败时保留原图，不显示旧译文，也不把空白结果当作成功。图片不上传，仅待译文字发送到已配置接口，关闭结果会取消当前任务。

## 验证范围

已完成截图原位覆盖、对照定位、长文本滚动、自动方向和缓存隔离测试。独立鼠标测试两次记录释放延迟为 16 ms、31 ms，后续移动不能改变选区；该数值来自本机固定图片，不代表所有硬件性能。

用两张固定中英文图片和现有 API 实测了“本机 OCR → 自动方向 → 翻译”：中文返回英文，英文返回中文。验证前后个人配置文件未改变，没有记录或上传密钥。另验证了固定中文图片在原位界面完成识别和翻译。

当前运行的输入法已占用 Ctrl＋Alt＋Z，回归没有抢占这个快捷键或向其发送测试按键。未改变的划词鼠标选区流程沿用 V1.1 已通过的独立检查；本轮重点验证新增的结果方向。完整系统覆盖安装及所有实际应用仍需后续使用验证。
