# 言渡输入法 V1.0

本次为 Android 和 Windows 的首个正式版本，应用版本统一为 1.0.0。此前上传的研发发布不计入正式版本，将在 V1.0 完成验证并发布后从 GitHub Releases 删除；本地历史备份继续保留。

- 名称统一为“言渡输入法”，共用项目图标、标语、浅深色和荧光绿点缀。
- 两端设置均按键盘、输入、翻译、隐私四类组织，Windows 改为横向分类。
- 官方更新仓库内置，用户无需填写。检查和下载只访问公开发布服务，不携带 AI 密钥或输入内容。
- GitHub 使用一个正式标签 v1.0.0，按附件类型区分 Android APK 与 Windows EXE，客户端不会互相下载。
- Android 下载后核对 SHA-256、包名、版本号、系统兼容和签名，再由系统确认安装。已有 API 配置和词库保留。
- Android 保留原包名和签名以支持旧版覆盖更新，关闭应用可调试标记；用户界面不显示内部构建变体名。
- Windows 保留原安装路径，版本检查和下载校验继续沿用已实现的保护。

版本代码：Android ARM64 1002、x86_64 1004。后续正式维护从 1.0.1 等版本递增，不复用本次标签或覆盖已发布的同名文件。

验证结果在发布前另行补充；本说明不替代实际构建与安装记录。
