# Windows V2.1（2.1.0）本地交付

本次在 V2.0 基础上调整安装维护与截图交互，尚未替换 GitHub 已发布的 V2.0。

## 安装与卸载

安装器核对真实程序文件，残留路径不能单独触发升级模式。统一使用“安装言渡”，目录按钮在首次安装及已有安装时均可用。迁移只接受空的专用目标目录，沿用当前用户的外置配置与词库，注册新路径后清理旧目录的已知程序文件；旧文件被占用时延后到重启清理。安装成功自动启动服务。

控制面板显示名为“言渡输入法”，发布者为用户指定的“yandu.github.com”，补充版本、安装日期和项目主页。该栏不等同于代码数字签名。

卸载界面统一品牌与配色，默认保留个人配置和学习词库。勾选“彻底卸载”才清除当前账号的配置、加密 API 密钥及词库、缓存，并删除言渡专属安装注册项。普通卸载也清除已知程序和启动入口。不会删除手动下载的安装包、源码备份、不相关文件和 Windows 系统日志；其它账号数据也不自动清理。同一账号管理员授权后才能彻底清理个人数据。

清理在删除前检查绝对路径及完整计划，拒绝系统根目录、越界路径或目录联接。被占用的已知程序及其空目录安排重启后删除；不声称 Windows 的所有历史记录立即消失。

## 更新提示

后台启动后检查公开 GitHub 正式版本；成功检查至少间隔 24 小时，应用持续运行时每小时检查是否到期或重试失败的请求。没有新版本不提示，离线不打断输入。

右下角通知提供升级、忽略此版本和取消。升级会下载，核对大小及 SHA-256 后以更新模式启动安装器，用户仍需通过 Windows 管理员确认。忽略记录在本机，取消不记为永久忽略；手动检查不受忽略限制。该功能不上传输入内容或 API 配置。

## 一套截图快捷键

“翻译”页只有一项共用截图快捷键，默认 Ctrl＋Alt＋Z，可自定义和检查冲突，保存后生效；留空关闭绑定。不会抢占已有快捷键，菜单仍可截图。

框选后自动复制原图，不执行 OCR 或翻译。需要翻译时点击同一截图工具栏上的“翻译”，复用该区域识别文字，再显示中英自动互译的原位覆盖／对照结果。

密码焦点检查仍然强制生效。普通截图不识别内容，不能承诺自动遮挡画面内所有未标注敏感文字；图片只写入本机剪贴板，之后的剪贴板云同步行为由系统／其它软件控制。

## 检查范围

隔离文件夹测试验证真实文件复制、迁移目标及清理计划、越界与联接拒绝、锁定文件不假报成功，并在 Windows PowerShell 5.1 复核。实际打开并取消本测试进程的文件夹选择框，核对卸载勾选项。

使用正常界面消息循环和固定图片检查共享快捷键冲突、自动复制的图像尺寸／像素，以及点击翻译前零 OCR／API 请求；验证右下角通知的升级、忽略和取消。没有卸载当前实际安装，也未执行真实系统目录迁移或未来版本在线覆盖安装；通知流程使用固定响应，文件下载校验沿用已验证的更新模块。

本机已通过：核心 32 项、界面 30 项、慢响应 21 项、更新策略 32 项与版本页 8 项；阅读 35 项、截图原位显示 41 项和词典／强制隐私 35 项。新增维护与共享截图界面 27 项、清理边界 19 项（Windows PowerShell 5.1 也通过），另实际核对目录框及卸载勾选项 6 项。UI 回归曾受桌面焦点影响，已在独立窗口复核；新截图测试使用主消息循环并等待翻译完成后关闭，避免测试异步生命周期与真实应用不同。
