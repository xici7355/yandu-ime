# Windows V1.1 阅读翻译

本版在 V1.0 基础上增加划词与截屏翻译。Android 仍为 V1.0，不随本次变更升级。V1.0 的 GitHub 发布和附件保持不变。

## 划词翻译

在支持 Windows 辅助功能选区的应用中，用鼠标选中文字，旁边出现“译”按钮。点击后打开原文和英文译文，可分别复制。选中文字本身不会请求 AI，不模拟 Ctrl+C，也不读取剪贴板。

按钮不抢原窗口焦点，切换窗口或等待约 8 秒后隐藏。点击时重新核对选区，旧选区不会用于翻译。密码输入框不读取。右键任务栏言渡图标可关闭划词翻译，也可在设置的“翻译”页修改后保存。

不支持辅助功能文字选区的应用可能不出现按钮，此时使用截屏翻译。受保护内容或权限不同的应用不保证可读取。

## 截屏翻译

按 **Ctrl＋Alt＋Z**，拖动框选文字区域；Esc 或右键取消。也可右键任务栏言渡图标选择“截屏翻译”，或从应用设置的“翻译”页打开。

截图先在本机识别中文和英文，再向现有 API 请求英文翻译。结果窗口显示识别原文和译文，提供“复制原文”和“复制译文”，不添加朗读。识别有误时可修正原文，再点击“重新翻译”。截图清晰、文字端正时识别效果更好，手写字和复杂版式可能不准确。

若快捷键已被其他软件占用，会显示提示并在任务栏菜单中注明；言渡不会抢占，仍可从菜单启动。没有新增替换、撤回或朗读快捷键，微信 Alt＋A 保持由原应用处理。

## 配置、隐私和取消

复用言渡的 API 地址、模型及加密密钥，不需要配置识图 API。未配置 API 或暂停联网翻译时，识别出的原文仍可复制。截图结果不会自动替换其他应用的内容。

截图为本地识别在用户配置目录 CaptureTemp 的随机子目录临时保存；识别完成、失败或取消后删除。图片不上传，只有待翻译文字发送到配置的 AI 服务。进程被强制终止或断电时可能留下临时目录，可在退出言渡后手动清理 CaptureTemp。选区与截图文字不写入诊断日志；翻译缓存沿用 V1.0 的内存缓存。

识别在单独进程运行，取消或超时会结束该进程。关闭结果窗口会取消待处理操作。辅助功能选区读取在后台进行，每次只允许一个任务，不阻塞输入线程；异常提供器可能使划词暂不可用，但不影响键盘和截图入口。

## 构建和验证

本地 OCR 使用 Tesseract .NET 5.2.0、Tesseract 5.2.0、Leptonica 1.82.0 和 tessdata_fast 的简体中文/英文模型。下载地址与 SHA-256 固定在 windows/personal/ocr-dependencies.json，完整许可随安装包提供。

构建前设置 YANDU_VC_REDIST_DIR，指向 VS 2022 的 VC/Redist/MSVC/14.44.35112/x64/Microsoft.VC143.CRT。prepare-ocr.ps1 会核对下载和运行库哈希。识别组件及模型随包附带，用户无需首次联网下载模型。

本机验证：51 项阅读功能检查、6 项隔离 Chrome 检查通过；原有逻辑 27 项、界面 25 项、慢响应 21 项、更新 32 项、隐私更新页 8 项继续通过；安装路径 21 项和安装器界面 20 项通过。包内实际识别程序验证通过，当前尚未执行 V1.1 在系统中的完整覆盖安装和所有聊天应用实测。

阅读功能检查包括实际离线 OCR、原文/译文与复制入口、密码框保护、鼠标选区浮标、截图裁切及取消、Ctrl＋Alt＋Z 实际消息与冲突检查。另在独立 Chrome 本地页核对网页选区和密码值排除；旧输入翻译逻辑、界面、慢响应和更新检查继续回归。测试使用虚构接口响应，没有向真实收费 API 发请求。

未覆盖所有软件、显示器缩放和版式，后续根据实际使用问题继续适配。
