# Windows 安装与使用

当前正式版为 **2.1.0**，支持 Windows 10/11 x64；实际测试环境为 Windows 11。

1. 从 [V2.1.0 发布页](https://github.com/xici7355/yandu-ime/releases/tag/v2.1.0) 下载 `Yandu-Setup-x64.exe`。同页提供 SHA-256 和源码。
2. 运行安装包，选择安装目录。已有安装默认沿用原路径；迁移请选择专用空文件夹。允许 Windows 管理员确认后完成安装。
3. 按 Win＋空格选择“言渡输入法”。从托盘右键菜单或开始菜单打开设置，在“翻译”页填写兼容 API 地址、模型和密钥，并测试接口。
4. 中文输入后显示译文，点击替换对应原文，再点同一区域撤回；喇叭控制朗读，右键展开全文。
5. 选中文字后点“译”启动划词翻译。默认 Ctrl＋Alt＋Z 框选截图，快捷键可在翻译设置中修改。框选后自动复制图片，可拖动或调整大小；点“复制截图”结束，点“翻译”识别并翻译。
6. 从控制面板卸载。默认保留配置和词库，勾选“彻底卸载”才删除当前账号的配置与学习数据。被其它应用加载的模块会安排重启后清理，无需为此关闭工作中的应用。

输入法模块更新后，已打开的软件可能仍使用旧模块，重开相关软件后生效。未配置 API 时仍可输入中文并查询内置词典，整句翻译需要 API。密码和典型敏感信息保护强制启用。

Windows V1.0／V2.0 的安装包继续保留在 [历史发布](https://github.com/xici7355/yandu-ime/releases)。Android 当前仍为 V1.0。
