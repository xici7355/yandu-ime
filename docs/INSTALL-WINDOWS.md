# Windows 安装与使用

当前版本：0.3.3。面向 Windows 10/11 x64，实际系统验收环境为 Windows 11。

## 安装

1. 从 [v0.3.3 发布页](https://github.com/xici7355/yandu-ime/releases/tag/v0.3.3) 下载 `Yandu-Setup-x64.exe`；同页提供 SHA-256。
2. 首次安装可修改路径，或点击“更改”选择上级目录。请选择本机固定磁盘上的专用空文件夹，默认是 `C:\Program Files\PersonalTranslateIme`。
3. 升级会自动识别并沿用旧路径，保留 API 配置和本地词库；升级界面不能直接迁移目录。
4. 点击安装或升级，允许 Windows 管理员授权。进度按实际解压字节、文件复制校验及系统注册步骤推进，成功后才显示 100%。
5. 点击“开始使用”，按 Win＋空格选择“言渡输入法”。首次词库初始化可能稍慢。

当前自用安装器没有商业代码签名证书，Windows 可能显示未知发布者。升级后请重开已经加载旧模块的微信或浏览器；系统图标仍有旧缓存时，重新登录 Windows 后刷新。

## 设置与翻译

右键任务栏的中/EN 图标或言渡图标，选择“言渡设置”；也可以从开始菜单打开设置。

在“翻译”页分别填写兼容 Chat Completions 的接口地址、模型名称和密钥。使用服务商提供的 HTTPS 地址；本机调试地址才允许 HTTP。不要把 `sk-` 密钥填入地址栏。

中文上屏后等待短暂停顿即可翻译。点击译文替换对应中文，再点同一位置撤回；继续输入、移动光标或切换输入框后，撤回目标会失效。右键译文在原卡片展开全文，超长内容可滚动。小喇叭播放，再点停止。

言渡不注册替换、撤回或朗读的全局快捷键；微信截图等快捷键由原应用设置和管理。

## 版本检查

“设置 → 隐私 → 版本与更新”显示当前版本。在更新仓库中填入 `xici7355/yandu-ime`，点击“检查更新”。当前 0.3.3 安装包的仓库默认仍为空，填写后保存即可。

新版下载安装包经过大小和 SHA-256 校验，之后由你确认打开安装器；不会静默安装。网络无法访问 GitHub 时，可从发布页手动下载，不影响本地输入。

## 配置与卸载

- API 设置：`%LOCALAPPDATA%\PersonalTranslateIme\settings.json`。密钥由当前 Windows 用户加密，换电脑需重新填写。
- 中文用户词库：`%APPDATA%\PersonalTranslateImeRime`。
- 程序目录与用户配置分开，正常升级不会覆盖个人配置。

切到其他输入法，再从 Windows“设置 → 应用”卸载言渡。个人配置和词库默认保留。若要迁移程序目录，应先卸载再重新安装，不能手动移动已注册的程序文件。

## 常见情况

没有译文时先确认已经填写 API 密钥、未暂停联网翻译，以及“测试接口”是否成功。密码框不会提供翻译。已有草稿、自绘编辑器或权限不同的应用可能不支持自动接管。

安装失败会显示未完成的进度和错误提示；本地 `install-error.log` 可用于排查。提交日志前请去掉用户名、路径和私人内容。不要将配置文件上传到 Issue。
