# Windows V2.1.2 本地修复包

基于 2.1.1，内部版本 2.1.2；尚未替换 GitHub 正式版。

## 划词确认

原逻辑只接受一个 UIA 文本范围，从鼠标所在控件向上查找的层数也较少；显示“译”后又连续读取选区并要求完全相等。格式化列表、深层标记或点击后收起的选区可能被当作失效，导致没有结果。

新版沿选区所在控件的祖先查找，不扫描整页正文；接受多个安全范围并保持顺序、去重，不读取未选中的间隔。保留标点和换行。鼠标抬起时立即记录是否点击“译”，避免按钮隐藏后又被误认为一次新的划词。浏览器确认后不再进行第三次选区读取；若选区收起或暂时不可重新定位，只有前台仍一致、密码焦点检查安全，且之前选中文本已通过校验时才使用该快照，强制对照显示，不覆盖错误位置。

受保护内容、过长选区和无法确认焦点安全的情况不能绕过保护。选区读取超时会给出提示，不会卡住键盘；UIA 待处理任务仍有数量限制。没有模拟 Ctrl+C，也不读取剪贴板来获取选中文字。

## 输入卡片

删除重复的原文标签及其显示代码，卡片缩短。保留译文、朗读／停止和来源／状态提示。替换及撤回仍使用内部精确原文快照，未取消范围校验；右键展开和滚动保留。

## 验证范围

隔离 Chrome 本地网页包含引号、顿号、多个列表项和换行，实际选区读取、点击后选区收起的确认与密码焦点拒绝共 14 项通过。原生独立文本控件验证真实多范围合并、不读间隔，以及点击触发和密码保护，共 18 项通过。

输入界面、异步响应、词典与截图检查另行执行。测试使用固定文本和响应，没有操作真实聊天草稿，也未以此保证所有应用的无障碍接口都兼容。若应用不公开选区或无法安全读取，仍需重选或使用截图翻译。
