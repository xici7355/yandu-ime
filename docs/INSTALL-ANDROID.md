# Android 安装与使用

言渡输入法 V1.0，应用版本 1.0.0。当前提供 ARM64 与 x86_64 安装包，支持 Android 6.0+。

## 安装

1. 从 [V1.0 发布页](https://github.com/xici7355/yandu-ime/releases/tag/v1.0.0) 下载匹配架构的 APK。常见 ARM64 手机选 Yandu-Android-arm64.apk；x86_64 设备或模拟器选对应包。
2. 按系统提示允许安装来源，然后启用并切换到“言渡输入法”。
3. 既有同包名、同签名安装可直接覆盖，API 配置、主题和本地数据保留。不要先卸载旧应用。

## 输入与翻译

从应用“翻译”页分别填写接口地址、模型和密钥，点击“验证连接”。接口须兼容 Chat Completions。密钥不是网址。

中文选词上屏后自动翻译。没有 API、断网或接口失败时保留中文，普通输入不受阻塞。

点击译文替换对应原文，长按查看全文；替换后 5 秒内可撤销，原文或光标变化后失效。小喇叭用于朗读和停止，声音取决于系统语音引擎与音色。

“123”进入独立数字键盘，符号只有中文、英文、常用三类。设置 → 键盘 → 主题与背景，可选择主题、自定义背景并跟随系统深浅色。

## 检查和安装更新

设置 → 隐私 → 检查更新。官方仓库已内置，不需要填写地址。

发现新版后点击“下载并更新”。程序核对下载大小、SHA-256、包名、版本、架构与签名，校验通过后打开系统安装界面。Android 8.0+ 首次会要求允许言渡作为安装来源，开启后返回即可继续安装。

安装必须由你在系统页面确认，不会后台静默安装。网络不可用时可以稍后重试或打开发布页下载；不会把 Windows 附件当成安卓更新。

## 数据和说明

API 密钥通过 Android Keystore 加密，更新不会重置密钥。应用包名和原签名为兼容升级保留；用户界面名称统一为言渡输入法，应用可调试标记已关闭。

当前没有离线整句翻译、图片或动图表情收藏，也不显示候选英文释义。不要把私人输入、密钥或完整配置上传到问题反馈。

具体验证范围见 PUBLICATION-VERIFICATION.md；不同厂商系统的音效、震感和安装确认页面可能不同。
