# Android 安装与使用

当前版本：第7版，`0.1.3-personal.7`，ARM64 versionCode 172。包名为 `personal.translate.ime.debug`；界面应用名称仍为“个人翻译输入法·测试版”。

## 安装

1. 从 [Android 第7版发布页](https://github.com/xici7355/yandu-ime/releases/tag/android-v7) 下载 `Yandu-Android-arm64-v7.apk`。
2. 当前 APK 仅适用于 ARM64 Android 6.0+。根据系统提示允许本次安装来源，再启用该输入法并切换使用。
3. 同包名、同签名的旧版本可覆盖更新，保留设置。其他人自行构建的 APK 通常使用不同签名，不能覆盖本发布包。

本次上传的是已交付的原始 APK，仅调整下载文件名，不重新打包、不更换包名和签名。

## 设置与输入

从应用打开四分类设置。在“翻译”中分别填写 API 服务地址、账号可用的模型名称和密钥；接口需兼容 Chat Completions。密钥不是网址。

选词上屏后自动翻译。未配置 API、离线或接口失败时，保留中文，普通输入可继续。

点击译文替换对应原文，长按查看完整译文。替换后 5 秒内可点击撤销；原文范围、光标或内容变化后撤销失效。小喇叭负责朗读和停止，音色取决于手机已安装的语音引擎。

“123”打开独立数字键盘；符号页仅保留中文、英文和常用三类，没有重复数字或空白页。设置 → 键盘 → 主题与背景，可切换主题、使用自定义背景并设置跟随系统深浅色。

没有候选词英文释义，也没有离线整句翻译及图片/动图表情收藏。中文词库学习在本机完成，不能代替翻译模型。

## 数据与验证范围

API 密钥通过 Android Keystore 加密保存，不随源码或 APK 发布，也不参与应用云备份。退出进程会清除内存翻译缓存。不要向维护者发送密钥、设备私有配置或敏感输入。

第7版完成 ARM64/x86_64 构建与五项模拟器回归，未使用真实付费 API 做延迟验收。当前发布的手机包只有 ARM64；其他架构需自行构建，未提供安装包。
