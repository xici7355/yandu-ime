# Windows V2.1.1 本地修复包

基于 2.1.0，内部版本 2.1.1；尚未替换 GitHub 的 V2.0 正式安装包。

- 修复点击“复制截图”后仍停留在截图界面的问题。仅复制成功后退出；剪贴板忙时保留界面和重试提示。Enter 或双击选区也可确认复制并退出。
- 框选完成后可拖动选区内部移动，拖动四边／四角调整大小。选区限制在冻结的桌面范围内，不能反转或缩小到无效尺寸；边角显示调整点，鼠标形状提示方向。
- 松开拖拽后复制新区域的图像，不执行 OCR 或请求 API。点击“翻译”后固定该区域，避免识别期间移动导致结果与图像不一致。划词翻译不增加图片选区调整。
- 保留 2.1.0 的共用快捷键、安装维护、发布者信息和隐私保护。

本机 37 项维护／共享截图检查通过，覆盖负坐标桌面边界、最小尺寸、真实窗口移动及缩放、更新后的剪贴板尺寸与像素、复制后窗口销毁和图片继续可用。原位截图显示回归 41 项通过。测试使用固定图像，不截取私有窗口，也未执行真实系统迁移或卸载。

GitHub V1.0 正式版仍保留 Windows／安卓安装包及源码。查看 https://github.com/xici7355/yandu-ime/releases/tag/v1.0.0 ，不要只查看 Latest 页面。
