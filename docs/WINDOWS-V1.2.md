# Windows V1.2 · 本地词典与阅读翻译

本次为本地试用交付，应用版本 1.2.0，尚未上传 GitHub Releases。Android 仍为 1.0.0。覆盖升级保留安装位置、API 配置和本地输入学习记录。

## 本地翻译怎么用

安装包直接包含 2026-11-10 的 CC-CEDICT 快照，共 125,403 条原始数据；中英双向压缩索引约 4.1 MiB，无需首次下载。词典随后续应用版本更新。

输入中文、划词和截屏都先尝试完整词条。命中显示“本地词典”；例如“输入法”“一路平安”以及英文“input method”可离线查询。英文反查来自释义索引，覆盖范围不等于独立英文词典。

未命中的句子不拆成零散词义拼接，配置 API 后交给模型翻译，并可附带相关公开词典释义辅助理解。重复的 API 结果可显示“内存缓存”。未配置 API 时，本地词典仍可用，普通输入不受影响。

词典释义可能有多义、生僻义或缺少上下文。划词／截屏命中后可点击“AI 精译”主动调用模型；没有 API 时该按钮不可用。词典不提供离线整句翻译模型，也不能保证每个英文词都有反向命中。

## 划词和截屏

选中文本后点击小“译”，结果直接在原文位置覆盖。打开“对照”后保留原文，将译文放在附近，超长时可滚动；不再打开独立居中的结果窗口。应用未提供可靠选区位置时只允许对照显示，避免覆盖错误位置。

Ctrl＋Alt＋Z 启动截屏，拖动后松开鼠标固定选区，Esc／右键取消。截图先在本机识别，随后复用相同的翻译流程。原文中文翻英文，原文英文翻中文；混合文本按主要语言判断。两种阅读界面只提供复制，不添加朗读。

## 强制隐私保护

密码框自动保护、典型敏感凭据拦截，没有关闭选项。不上传个人词库或缓存，也不收集输入资料用于改进或训练。截图识别使用内存管道，不生成新的临时图片／文本文件。保护覆盖范围、第三方 API 的边界和旧版临时文件说明见 [隐私说明](PRIVACY.md)。

## 验证范围

本机检查真实 CC-CEDICT 查询、离线无请求、整句 API 回退和缓存（固定本地响应），并验证保护不能被精译绕过。界面和本地 OCR 回归同时运行。本次不以固定响应测试声称远程模型准确率，也未宣称全部 Windows 应用兼容。安装包最终校验结果随本地交付记录提供。
