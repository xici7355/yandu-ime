# 隐私与敏感文件

普通拼音解码、候选和本地词频学习在设备上完成。配置 API 并启用翻译后，待译文字发送给你选择的 AI 服务；实际数据处理方式取决于该服务商。语音引擎可能具有自身的网络行为，应查看系统音色设置。

Windows 的 API 密钥由当前用户的 DPAPI 加密；Android 使用 Android Keystore。源码中的默认配置不含个人密钥。安装包不包含用户目录的设置、词库学习记录或私人草稿。

Windows 更新检查只访问用户填写的公开 GitHub 仓库，不传输输入内容或 AI 密钥。当前安装包默认不设置更新仓库，只在手动检查时联网。

## 不应提交的文件

- 真实 API 配置、`settings.json`、应用私有 SharedPreferences、数据库和个人用户词库。
- `.env`、GitHub 令牌、密码、个人代理或带访问凭据的链接。
- Android 签名私钥、JKS/keystore、PFX/P12，以及恢复私钥所需的密码说明。
- `local.properties`、个人构建环境文件、缓存、设备导出和原始诊断日志。

`.gitignore` 和 `tools/check_publication.py` 帮助发现误提交，但仍需审查实际暂存区。私钥应单独离线备份；不要因为配置被加密，就把其密文上传到公开仓库。

提交 Issue 前请移除密钥和私人文本。请不要公开上传完整设置文件或带账号信息的录屏。
