# 隐私与敏感文件

普通拼音解码、候选和本地词频学习在设备上完成。配置 API 并启用翻译后，待译文字发送给你选择的 AI 服务；实际数据处理方式取决于该服务商。语音引擎可能具有自身的网络行为，应查看系统音色设置。

Windows 的 API 密钥由当前用户的 DPAPI 加密；Android 使用 Android Keystore。源码中的默认配置不含个人密钥。安装包不包含用户目录的设置、词库学习记录或私人草稿。

两端更新源固定为言渡官方公开 GitHub 仓库，不传输输入内容或 AI 密钥，V1.0 只在手动检查和下载时联网（Windows V2.1 的自动检查见文末）。安卓安装更新需要用户允许安装来源并在系统页面确认；文件提供器只开放更新缓存中的安装包，不开放 API 配置目录。

## 不应提交的文件

- 真实 API 配置、`settings.json`、应用私有 SharedPreferences、数据库和个人用户词库。
- `.env`、GitHub 令牌、密码、个人代理或带访问凭据的链接。
- Android 签名私钥、JKS/keystore、PFX/P12，以及恢复私钥所需的密码说明。
- `local.properties`、个人构建环境文件、缓存、设备导出和原始诊断日志。

`.gitignore` 和 `tools/check_publication.py` 帮助发现误提交，但仍需审查实际暂存区。私钥应单独离线备份；不要因为配置被加密，就把其密文上传到公开仓库。

提交 Issue 前请移除密钥和私人文本。请不要公开上传完整设置文件或带账号信息的录屏。

## Windows V1.2 强制保护

以下规则没有关闭开关，也不能通过“AI 精译”绕过。

- 系统标记为密码的输入框，以及可识别的密码／密钥编辑框，不读取和翻译；划词也跳过这些控件。截屏启动前检查焦点控件，无法在限定时间确认安全时拒绝启动。
- 在词典查询、缓存和 API 请求之前检查典型敏感内容，包括密钥、带凭据的链接、邮箱，以及常见手机号、身份证号和银行卡号形式。命中后不请求、不加入翻译缓存；API 返回内容也经过同一检查。
- 已识别的敏感截图文字会清除结果状态并遮挡选区，禁止复制和重试。截图识别在内存和本机子进程管道中完成，新版不生成图片或 OCR 文本临时文件。
- 不上传个人词库、输入学习记录或翻译缓存，不收集输入文字用于改进或训练。Rime 的个性化词频保留在本机；翻译缓存最多 128 项，仅在内存中，退出清空。

保护依赖应用正确公开密码属性或可识别的字段信息，并覆盖典型敏感内容格式。自绘控件、未标注字段及任意私人叙述不能保证全部识别；这不是完整的数据防泄漏系统。旧版强制退出后留下的 CaptureTemp 文件不会因升级自动消失，可在退出言渡后手动清理。

## Windows V1.2 本地优先与联网边界

CC-CEDICT 是随安装包提供的公开词典。完整词语／固定短语命中时直接本地返回，不发送查询词，也不保存查询历史。未命中的整句在已配置并允许联网翻译时交给 API；没有 API 时保留普通输入能力。API 可收到本次文本中的相关公开词典释义作为参考，不会附带用户词库或历史缓存。

只有点击“译”后才为划词发起翻译。选区来自当前应用公开的选区接口，不读取剪贴板或模拟复制；点击复制按钮才写剪贴板。截图图片不上传，只有允许联网翻译的普通识别文本会发送到所选 API。

应用自身不收集训练资料，不代表第三方 API 服务商承诺不留存或不训练。配置远程 API 时应查看其规则；要让普通待译文本也不离开本机，可使用兼容接口的本机模型。系统剪贴板、截图内容在内存中的存在，以及操作系统备份或其他软件的行为，不由言渡保证。

词典随应用版本更新，不后台定时联网更新，不上传用户内容来改进词典。

## Windows V2.1 本地维护版

新版按用户要求在后台检查公开 GitHub 版本信息：启动时检查到期状态，成功后至少间隔 24 小时；持续运行时每小时检查到期或重试网络失败。检查不发送输入文字、词库、API 密钥或个人缓存，忽略版本只记在本机，不作遥测。手动检查入口保留。

共用截图流程在框选后自动把图片写入本机剪贴板，点击“翻译”才执行 OCR／翻译。普通截图不识别内容，密码焦点检查仍强制启用；不能保证发现截图里所有未标注的敏感文字。Windows 剪贴板历史、云同步和其它软件后续读取不由言渡控制。

彻底卸载为主动勾选项，删除当前用户的配置、加密密钥和学习词库，包含应用管理的更新缓存。普通卸载保留个人数据；手动保存的安装包、源码备份及系统日志不自动删除。仅清理言渡已知程序与专属注册项，不承诺清除 Windows 的所有历史记录；被占用的程序文件需重启后删除。

若点击翻译后检测到敏感内容，会清除结果并遮挡选区；只有剪贴板仍是本次截图时才清空该图片，不会覆盖用户之后复制的新内容。此前已进入系统剪贴板历史或第三方同步的副本不由言渡保证清除。
