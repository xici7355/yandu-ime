言渡输入法 Windows V1.2（1.2.0）
落笔此岸，言达彼岸。

安装升级
直接运行安装器覆盖升级，沿用 V1.0 的目录、API 配置和本地词库。不要先卸载。需要 Windows 10/11 x64 和系统管理员确认。升级后重开已加载旧模块的应用。

打开设置
右键任务栏言渡图标选择“言渡设置”，也可从开始菜单打开。设置仍按键盘、输入、翻译、隐私分类。

输入翻译
在“翻译”页分别填写接口地址、模型及 API 密钥，点击“验证连接”。中文上屏后自动翻译；点击译文替换对应原文，再点同一位置撤回。右键译文在原卡片展开。原来的小喇叭朗读交互保留。

划词翻译
用鼠标选中文字，点击旁边“译”按钮，自动识别中文或英文，分别翻成英文或中文，可复制。选中文本不会自动调用 API。结果与截屏共用原位覆盖／对照界面，不再另开居中结果窗口。可在任务栏右键菜单或“翻译”设置中关闭。
只读取应用公开的选区，不读取剪贴板，不模拟复制快捷键。密码框跳过。未显示“译”按钮的软件可使用截屏翻译。

截屏翻译
Ctrl＋Alt＋Z：拖动框选区域，Esc 或右键取消。也可从任务栏右键菜单启动。
松开鼠标后选区固定，译文显示在截图上。原文中文就译英文，原文英文就译中文。关闭“对照”覆盖原图文字；打开“对照”保留原图，译文在附近完整显示，超长可滚动。提供复制译文、复制原文和重试，不添加朗读。复用现有 API 配置，无需识图模型；未配置接口仍可复制识别原文。
如果快捷键被占用会明确提示，不会抢占其他软件。没有新增替换、撤回或朗读快捷键。

本地词典
内置 CC-CEDICT 125,403 条原始词条的中英双向索引，压缩约 4.1 MiB。完整词语／固定短语命中显示“本地词典”，不调用 API。未命中的整句不机械拼接词义，配置 API 后由模型翻译；没有 API 保留普通输入。阅读结果可点“AI 精译”，主动使用 API。词典随应用版本更新，许可为 CC BY-SA 4.0，来源与全文许可位于安装目录 Dictionary。

隐私与临时文件
密码框保护和典型敏感信息拦截强制启用，不能关闭；命中后不发送、不缓存。不上传个人词库、学习记录或翻译缓存，不收集输入资料用于改进或训练。保护不能保证识别全部未标注字段和任意私人文字。
截图不上传，OCR 使用内存管道，不生成新的临时图片／文本文件；旧版残留可在退出后手动删除。API 回退仍发送本次普通待译文字，第三方服务商的留存规则需自行查看。翻译缓存仅在内存，退出清空。
配置位于 %LOCALAPPDATA%\PersonalTranslateIme，密钥由当前用户加密。词库位于 %APPDATA%\PersonalTranslateImeRime。不要公开上传配置文件或私钥。

在线更新
在“隐私”页检查官方 GitHub 正式版本。升级会保留配置。V1.0 发布附件不被本次开发覆盖。

说明
中文/英文 OCR 模型和运行组件随安装包提供，不保证所有截图和软件都兼容。截图应清晰，避免文字过小。更多说明见源码 docs/WINDOWS-V1.2.md。
