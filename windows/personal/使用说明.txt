言渡输入法 Windows V2.1（2.1.0）
落笔此岸，言达彼岸。

安装与迁移
直接运行安装器。首次安装和重装统一显示“安装言渡”，更改按钮可打开目录选择框。默认沿用已有目录，也可选择另一个空目录迁移；已有 API 配置和用户词库保留。新目录完成注册后才清理旧目录的已知程序文件；被占用的文件可能要重启后删除。不要选择包含其他程序的非空目录。
安装成功会启动言渡服务。控制面板名称为“言渡输入法”，发布者显示“yandu.github.com”，版本 2.1.0。发布者栏属于显示信息，不等同于数字签名。升级后重开浏览器、微信等已加载旧模块的软件。

共用截图快捷键
默认 Ctrl＋Alt＋Z，也可在应用“翻译”页自定义，点击“检查冲突”后保存。只有一个快捷键，普通截图与截图翻译共用；留空关闭快捷键，菜单入口保留。发生冲突不会抢占其他应用。
按快捷键后拖动框选，松开固定区域，Esc／右键取消。选定后自动把图片复制到剪贴板，可直接粘贴到微信等支持图片的应用。界面上点击“翻译”才执行本机 OCR 和翻译；普通截图不会识别或调用 API。
翻译时中文译英文、英文译中文。关闭“对照”覆盖原文，打开后在附近查看完整译文，过长可滚动；可复制译文和原文。不添加阅读朗读快捷键。

自动更新
启动后自动检查官方 GitHub 正式版本，成功检查间隔至少 24 小时；持续运行时也会定期重试。发现更高版本后在右下角提示。点“升级”自动下载，核对大小和 SHA-256 后启动覆盖安装流程，仍需 Windows 管理员确认；“忽略此版本”不再提示该版本，“取消”只关闭提示。离线不打断输入，也可随时从隐私页手动检查。
自动检查只请求公开版本信息，不上传输入内容或 API 配置。当前本地 2.1.0 包不会把 GitHub 上的 2.0.0 当成升级。

卸载
从 Windows 已安装的应用或控制面板卸载。新版界面默认不勾选“彻底卸载”：删除程序、启动入口和言渡专属安装注册项，保留 API 配置和学习词库。
勾选后还会删除当前用户的配置、加密密钥、学习词库及应用管理的更新缓存。不会删除你在下载目录手动保存的安装器、源码备份或 Windows 系统日志。为避免误删别的软件，安装目录内用户另放的不相关文件会保留。被占用的输入模块和卸载程序安排重启后删除；如要在同一目录重新安装，请先完成重启清理。
彻底卸载需由同一 Windows 账号进行管理员授权，避免误删其它账号的数据。其它 Windows 账号中的个人数据不自动清理。

原有功能
中文全拼、英文输入、完整原文截取和点击译文替换／撤回保留。右键译文展开，小喇叭朗读与停止。设置从任务栏言渡图标右键或开始菜单打开。
CC-CEDICT 125,403 条原始词条的双向索引随包提供，完整词语／短语优先本地翻译，未命中整句再使用 API。词典不是离线整句模型，随应用版本更新，许可与来源在 Dictionary 文件夹。
密码保护和典型敏感信息拦截强制启用。不上传用户词库或翻译缓存，不收集输入资料用于改进或训练。截图识别使用内存管道，不生成新的临时图片文件；普通截图不识别图片内容，密码焦点保护仍生效，但不能保证发现画面中所有未标注的敏感文字。远程 API 的留存规则由服务商决定。
