# Windows 安装与使用

言渡输入法 V1.0，应用版本 1.0.0。面向 Windows 10/11 x64，本机实际验收环境为 Windows 11。

## 安装与启动

1. 从 [V1.0 发布页](https://github.com/xici7355/yandu-ime/releases/tag/v1.0.0) 下载 Yandu-Setup-x64.exe。同页提供 SHA-256。
2. 首次安装可修改目录，或点“更改”选择上级目录。请选择本机固定磁盘上的专用空文件夹。已有安装会自动沿用原路径，升级不能直接迁移目录。
3. 点击安装或升级，允许管理员确认。进度按实际解压、复制校验及系统注册推进，全部成功才显示 100%。
4. 点击“开始使用”，按 Win＋空格选择言渡。首次词库初始化可能稍慢。

当前安装器没有商业代码签名证书，Windows 可能显示未知发布者。升级后重开已经加载旧模块的微信、浏览器等应用；系统图标缓存未更新时，重新登录 Windows 刷新。

## 设置、翻译与朗读

右键任务栏输入法图标选择“言渡设置”，或从开始菜单打开。设置按键盘、输入、翻译、隐私四类横向排列。

“翻译”页分别填写兼容 Chat Completions 的 HTTPS 接口地址、模型和密钥，点击“验证连接”。`sk-` 密钥应填入密钥栏。只有本机调试地址允许 HTTP。

中文上屏后自动翻译。点击译文替换，再点同一位置撤回；继续输入、移动光标或切换输入框后，撤回目标失效。右键译文在原卡片展开全文，超长内容可滚动。小喇叭用于播放和停止。

言渡不注册替换、撤回或朗读的全局快捷键。微信截图等组合键仍由原应用管理。

## 在线更新

“隐私”页显示当前版本和官方更新源。仓库已内置，无需填写；点击“检查更新”即可查询正式版本。

发现新版后，下载并核对大小及 SHA-256，再由你确认打开安装器。升级保留旧目录和已保存的 API 配置，不会静默安装。

## 配置与卸载

API 设置在 `%LOCALAPPDATA%\PersonalTranslateIme\settings.json`，密钥由当前 Windows 用户加密；换电脑需重新填写。用户词库在 `%APPDATA%\PersonalTranslateImeRime`，与程序目录分开。

卸载前切到其他输入法，再从 Windows“设置 → 应用”卸载言渡。个人配置与词库默认保留。若要迁移目录，请先卸载再安装，不能手动移动已注册的程序文件。

## 排查

没有译文时检查 API 是否已配置、是否暂停联网翻译及“验证连接”结果。密码框不启用翻译；已有草稿、自绘编辑器或权限不同的应用可能需要单独适配。

安装失败会显示未完成进度和原因。本地 install-error.log 可用于排查，提交前请移除私人路径和内容；不要上传完整配置文件。
