言渡输入法 Windows V1.1（1.1.0）
落笔此岸，言达彼岸。

安装升级
直接运行安装器覆盖升级，沿用 V1.0 的目录、API 配置和本地词库。不要先卸载。需要 Windows 10/11 x64 和系统管理员确认。升级后重开已加载旧模块的应用。

打开设置
右键任务栏言渡图标选择“言渡设置”，也可从开始菜单打开。设置仍按键盘、输入、翻译、隐私分类。

输入翻译
在“翻译”页分别填写接口地址、模型及 API 密钥，点击“验证连接”。中文上屏后自动翻译；点击译文替换对应原文，再点同一位置撤回。右键译文在原卡片展开。原来的小喇叭朗读交互保留。

划词翻译
用鼠标选中文字，点击旁边“译”按钮，查看原文和英文译文，可分别复制。选中文本不会自动调用 API。可在任务栏右键菜单或“翻译”设置中关闭。
只读取应用公开的选区，不读取剪贴板，不模拟复制快捷键。密码框跳过。未显示“译”按钮的软件可使用截屏翻译。

截屏翻译
Ctrl＋Alt＋Z：拖动框选区域，Esc 或右键取消。也可从任务栏右键菜单启动。
本机识别后显示原文及英文，可复制，不添加朗读。识别错误时可修改原文，再点“重新翻译”。复用现有 API 配置，不需要识图模型；未配置接口仍可复制识别原文。
如果快捷键被占用会明确提示，不会抢占其他软件。没有新增替换、撤回或朗读快捷键。

隐私与临时文件
截图不上传。识别过程在本机临时保存图片，完成或取消后删除；只有识别出的文字发到你配置的翻译接口。断电或强制退出可能留下 CaptureTemp 临时目录，可在退出言渡后删除。
配置位于 %LOCALAPPDATA%\PersonalTranslateIme，密钥由当前用户加密。词库位于 %APPDATA%\PersonalTranslateImeRime。不要公开上传配置文件或私钥。

在线更新
在“隐私”页检查官方 GitHub 正式版本。升级会保留配置。V1.0 发布附件不被本次开发覆盖。

说明
中文/英文 OCR 模型和运行组件随安装包提供，不保证所有截图和软件都兼容。截图应清晰，避免文字过小。更多说明见源码 docs/WINDOWS-V1.1.md。
